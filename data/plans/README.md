# Drawn plans

One file per building (`<project>/<building>.json`) describing the building **as it stands**: frame on the
footprint, column grid, cores, atrium, facade, and per floor type the partitions, doors and named rooms.
The explorer builds today's floors from it (`parametric/mvk/plan.py`), and a floor keeps its drawn layout as
long as its use is the drawn use. Any other use is still generated by `parametric/mvk/layout.py`.

A building points to its plan with `"plan": "data/plans/..."` in `parametric/site/marievik_site.json`.

Replace a mock-up with surveyed drawings by editing the same file; keep `_meta.source` and `_meta.assumptions`
up to date, because every result built on the plan inherits them.
