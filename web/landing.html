About the lab

Marievik+ tests how one building shell can serve different uses, different user groups and different time horizons — and what each transformation costs, in SEK and in kg CO₂e. It is a computational platform for adaptive reuse, built with Chalmers Next Labs.

Every run follows the same loop, from what already exists to what a change would create:

  • Retain — what exists
  • Enable — what room for action
  • Adapt — what's needed now
  • Implement — what happens trying
  • Evaluate — what value, what cost
